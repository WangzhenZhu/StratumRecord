# StratumRecord 运行说明

## 已完成的功能

✅ **策略记录页面**
- 创建和保存游戏策略
- 选择游戏或自定义游戏名称
- 设置策略标题和内容
- 标记重要性级别（高、中、低）
- 查看、编辑、删除策略

✅ **策略广场**
- 浏览社区策略
- 点赞、评论、分享策略
- 发布自己的策略
- 举报和屏蔽功能

✅ **策略详情**
- 查看完整策略内容
- 浏览和发表评论
- 评论审核机制
- 举报策略/评论

✅ **设置页面**
- 清除缓存
- 隐私政策
- 版本信息 (v1.0.0)
- 反馈
- 分享应用
- 应用评分

## 如何运行

1. **重要**: 使用 Xcode 打开 `StratumRecord.xcworkspace` 文件（不是 .xcodeproj）

2. 选择模拟器或真机设备

3. 按 `Cmd + R` 编译运行

## 技术实现

- **语言**: Objective-C
- **UI框架**: 纯代码实现（无 Storyboard）
- **布局工具**: Masonry
- **网络库**: AFNetworking
- **数据存储**: NSUserDefaults + NSCoding

## 特色功能

1. **三色重要性标记**
   - 🔴 高 (红色)
   - 🟡 中 (橙色)
   - 🔵 低 (蓝色)

2. **内置模拟数据**
   - 包含6个示例策略
   - 涵盖主流游戏（英雄联盟、绝地求生、守望先锋等）

3. **无需登录**
   - 本地存储所有数据
   - 保护用户隐私

## App 结构

```
📱 StratumRecord
├── 📝 Record (记录) - 个人策略列表
├── 🏛️ Plaza (广场) - 社区策略
└── ⚙️ Settings (设置) - 应用设置
```

## 颜色主题

- 主色调: 青绿色 (#26B5A8)
- 背景色: 浅灰色 (#F5F5F5)
- 卡片: 白色带阴影

## 项目文件说明

所有源文件都已添加到 Xcode 项目中，包括：

- 数据模型 (SRStrategy, SRComment)
- 视图控制器 (SRRecordViewController, SRPlazaViewController 等)
- 自定义视图单元格 (SRStrategyCell, SRPlazaCell)
- 数据管理器 (SRDataManager)
- 常量和配置 (SRConstants)

## 遇到问题？

如果编译出错，请确保：
1. 使用 `.xcworkspace` 文件打开项目
2. CocoaPods 依赖已正确安装
3. 选择了正确的编译目标（iOS 12.0+）
